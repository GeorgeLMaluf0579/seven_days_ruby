# Seven days ruby
A language study program covering the most common topics encountered in the day-to-day life of a Ruby developer.

## Day 01 - Arrays and Enumerable
- .each - execute some for each element
- .map - transform each element
- .select - select elements
- .reject - reject elements
- .find - find one element
- .reduce - combine elements in to one result
- .group_by - group elements
- .sort_by - order elements
- .any? - almost one element 
- .all? - all elements
- .none?  - none of elements

## Day 02 - Hash
- hash[:key] - access value
- fetch - access value if exists
- merge - combine hashs
- transform_values - transform values
- transform_keys - tranform keys
- dig - access nested structures
- slice - select keys
- except - remove keys
- Hash.new(0) - criar counters
- Hash.new{ ... } - grouping
